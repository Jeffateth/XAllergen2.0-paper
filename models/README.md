# Model Checkpoints

This directory contains the trained model checkpoints for the paper:

> **Residue-Level Attributions in Protein Language Models Do Not Recover Allergen Epitopes**
> Jianzhou Yao, Anxiong Song, Katja Baerenfaller, Damir Zhakparov
> ICML 2026 Workshop on Mechanistic Interpretability

## Checkpoints

### `baseline_frozen_esm2.pt`

| Property | Value |
|----------|-------|
| Model | ESM-2 (`facebook/esm2_t6_8M_UR50D`) + frozen backbone + MLP classification head |
| Paper experiment | Baseline allergenicity classifier (frozen ESM-2, protein-level) |
| File size | ~30 MB |
| Needed for figure reproduction | Yes (without retraining) |
| Regenerated by | `notebooks/03_baseline_model_esm2.ipynb` |
| Base model source | Downloaded automatically from Hugging Face Hub on first use |

The backbone weights are the frozen pre-trained ESM-2 parameters from Meta AI.
Only the MLP classification head was trained on the XAllergen dataset.

## ESM-2 Base Model

The ESM-2 backbone (`facebook/esm2_t6_8M_UR50D`) is **not included** in this
repository. It is downloaded automatically from Hugging Face Hub on first use:

```python
# Handled automatically by src/xallergen/baseline_notebook_utils.py
from xallergen.baseline_notebook_utils import resolve_hf_model_source
model_path = resolve_hf_model_source()  # checks local cache, then HF Hub
```

If you have a local Hugging Face cache, set the environment variable:

```bash
export XALLERGEN_HF_MODEL_DIR=/path/to/local/esm2_t6_8M_UR50D/snapshot
```

## Loading Checkpoints

Checkpoints are standard PyTorch state dicts. Example:

```python
import torch
checkpoint = torch.load("models/baseline_frozen_esm2.pt", map_location="cpu")
```

The correct model class and hyperparameters for each checkpoint are defined in
the corresponding training notebook. The shared utilities in
`src/xallergen/baseline_notebook_utils.py` contain the model architecture
definitions used for training and inference.

## Reproducing Results Without Retraining

Notebooks 06–09 load the saved checkpoints from this directory and do not
require GPU retraining. To reproduce all paper figures and tables:

1. Ensure checkpoints are present in `models/`
2. Run `notebooks/06_generate_probe_rows.ipynb` (CPU, ~30–60 min)
3. Run `notebooks/07_insilico_mutagenesis.ipynb` (CPU or GPU)
4. Run `notebooks/08_compare_all_model_probes.ipynb` (CPU, fast)
5. Run `notebooks/09_unfiltered_ig_masking_sensitivity.ipynb` (CPU)

Precomputed probe rows are already saved in `results/probing/rows/` and
mutagenesis results in `results/insilico_mutagenesis/`, so the full
figure set can be reproduced by running only notebook 08.
